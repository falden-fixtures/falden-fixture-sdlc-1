# Security

Report a security problem in this repository privately, by email to release@falden.ai, and do not open a public issue for it.

This repository is a test fixture, and its history is deliberately anomalous. What the README lists as there on purpose is not a security problem.

What to report:

- a credential, a private key, a personal email address or any other private data in a file or a commit of this repository
- the workflow in `.github/workflows/attest.yml` started by anything but a workflow dispatch, or signing anything but the statement it writes

Say which commit and which file, and what you saw.
